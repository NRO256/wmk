1. 概要
  WMK は、Windows 標準のシステム修復・時刻同期・システム情報取得・
  ネットワーク一括修復の各種 CLI コマンドを、単一の軽量ポータブル
  GUI（一画面構成・外部依存なし・レジストリ不使用）から安全に実行
  できるメンテナンスツールです。
  キーボード操作（Tab移動・アクセスキー・ログ欄でのCtrl+A/Esc）
  およびスクリーンリーダー（NVDA / ナレーター）での読み上げに配慮した
  標準 Win32 ネイティブ UI を採用しています。

2. 主な機能
  - 基本メンテナンス・診断:
    - DISM オンライン修復 (&D):
      DISM.exe /Online /Cleanup-Image /RestoreHealth
    - SFC スキャン (&C):
      sfc.exe /scannow
    - ネットワーク一括修復 (&N):
      実行前の確認ダイアログ後、以下を順次実行します。
      netsh.exe winsock reset / netsh.exe int ip reset / ipconfig.exe /flushdns
    - NTP 時刻同期 (&T):
      w32tm.exe /resync
    - システム情報取得 (&V):
      systeminfo.exe の結果をログ欄へ出力します。

  - ディスク・オフライン修復:
    - CHKDSK 修復 (&K):
      利用可能な固定・リムーバブルドライブから対象を選択し、
      実行前の確認ダイアログ後、chkdsk.exe <ドライブ>: /r を実行します
      （使用中ドライブ等で再起動予約の入力が求められた場合は自動応答します）。
    - DISM ソース指定修復 (/LimitAccess) (&M):
      フォルダ（「フォルダ(&F)...」）または WIM/ESD ファイル
      （「WIM/ESD(&W)...」）を指定し、インデックス番号（1〜10）を選択して
      修復を実行します。
      ※ 入力欄に直接「WIM:<パス>:<番号>」または「ESD:<パス>:<番号>」
         形式を指定することも可能です。
      ※ ポータブル運用対応: WMK.exe と同じフォルダ、または sources
         サブフォルダに install.wim / install.esd を配置しておくと、
         起動時に自動検出して修復ソース欄へ自動セットします
         （優先順: 同階層 install.wim -> 同階層 install.esd ->
          sources\install.wim -> sources\install.esd）。

  - 実行制御・ログ機能:
    - 非同期実行・リアルタイム出力（UTF-8 / CP932 / UTF-16LE 自動判定）
    - 実行中は経過時間 [MM:SS] とマーキープログレスバーを表示し、設定入力の誤変更をロックします
    - 実行中はシステムのスリープ移行を抑止します（SetThreadExecutionState）
    - 実行中断 (&X) 時は Job Object により子プロセスツリー全体を一括終了します
    - 開始・完了行への時刻スタンプ [HH:MM:SS]、所要時間、終了コード案内を表示します
    - コマンド開始・完了・中断・エラー時に UI Automation 経由でスクリーンリーダーへ通知します
    - 実行ログ上限（保存バッファ 512 KiB / 画面表示 512K 文字）超過時は古い行を自動トリミングします
    - ログクリア (&L)、UTF-8 テキストファイル保存 (&S)

3. 使い方
  1. WMK.exe を起動します（内蔵マニフェストにより管理者権限の確認
     ダイアログが表示されます）。
  2. 必要に応じて CHKDSK の対象ドライブや DISM の修復ソースを指定し、
     実行したいメンテナンスボタンを選択します。
  3. ログ欄で実行状況を確認し、必要に応じて「ログ保存」から UTF-8
     テキストファイル（既定名: wmk_log.txt）として保存してください。

4. キーボード操作・スクリーンリーダー対応
  - Tab / Shift+Tab:
    各コントロール間を移動します。読み取り専用の複数行ログ欄からも
    Tab / Shift+Tab でそのまま前後へフォーカス移動できます。
  - Alt + アクセスキー:
    各ボタンへ直接移動・実行します（D: DISMオンライン / C: SFC /
    N: ネットワーク修復 / T: NTP同期 / V: システム情報 / K: CHKDSK /
    F: フォルダ選択 / W: WIM/ESD選択 / M: DISMソース指定実行 /
    X: 実行中断 / L: ログクリア / S: ログ保存）。
  - Ctrl+A:
    実行ログ欄で全文を選択します（制御文字による警告音を抑止済み）。
  - Esc:
    実行ログ欄から先頭の操作ボタン（実行中時は「実行中断」）へ
    フォーカスを戻します。
  - ログ閲覧中カーソル保護・実行時フォーカス復帰:
    実行ログ欄を閲覧中に新しい行が追記されても選択位置とスクロール位置を維持します。
    コマンド開始時は無効化前に「実行中断」ボタンへフォーカスを退避し、
    完了時は元のボタンへフォーカスを復帰します。

5. 注意事項・免責
  - CHKDSK /r やネットワーク設定リセットは処理に時間がかかる場合や、
    システム再起動を伴う場合があります。確認ダイアログの内容をよく
    確認のうえ実行してください。
  - 本ソフトウェアの利用により生じたデータ損失等の損害について、
    作成者は責任を負いかねます。重要なデータは事前にバックアップした
    うえでご使用ください。

6. 動作環境・ファイル構成・ビルド方法
  - 動作環境: Windows 11 (x64) / 管理者権限必須（UACマニフェスト内蔵）
  - 構成ファイル:
    WMK.exe     本体実行ファイル（単一ファイル完結・レジストリ不使用）
    README.txt  本取扱説明書
  - ビルド・テスト方法（開発者向け / Rust Edition 2024 + MSVC 2022）:
    cargo fmt --check
    cargo clippy --all-targets -- -D warnings
    cargo test --lib
    cargo build --release
